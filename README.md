# 🥤 JuiceMall - Fresh Juiceables

JuiceMall is a fresh and 100% natural juice website.
Get Fresh Juiceables Everyday - Kiwi, Strawberry & Orange.

## ✨ Features
- 100% Natural & Fresh Juices
- Auto Change Juice Flavours Every 3 Seconds
- Smooth Color Transition Animation
- Clickable Dots to Change Flavour
- Fully Responsive - Works on Mobile & Laptop
- Modern & Clean Design

## 🍹 Flavours
- 🥝 Kiwi - Pure taste. Better health.
- 🍓 Strawberry - Sweet & delicious.
- 🍊 Orange - Full of Vitamin C.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How To Open Website
1. Download this repository
2. Open `index.html` file in browser
3. Enjoy Fresh Juiceables!
